# Practice focus review — 12 November 2026

All 298 active questions were reviewed against their prompt, code (when present), correct answer, and explanation. Focus is a learning activity, not an estimated difficulty. A code block alone does not make a question a scenario.

- **Fundamentals:** explain a concept, command, field, option, module, or standard behavior directly. Examples include `flush_handlers`, the `checks.results` field, quoted file modes, state locking, and the hostname topology key.
- **Scenarios:** apply knowledge to a concrete case: trace selected hosts or loop results, combine permissions/constraints, diagnose a symptom, select a recovery action, or predict an operational outcome. Examples include a Bash redirection trace, an image rollout blocked by scheduling, serial-batch `run_once`, and a divergent Git branch.
- **Mixed:** all questions, without filtering. It is selected in the app and never stored as a question tag.

Use the main skill the learner must demonstrate to choose the answer. Directly naming a setting remains Fundamentals even when shown in YAML; reasoning through several inputs or an incident belongs in Scenarios. Categories are not artificially balanced: the existing banks contain different proportions of these activities. New questions must have an explicit tag, and both filters must have content in each active topic.

New rounds sample that category; continuing an existing round preserves its already-selected questions. Tags and answer-reference examples are excluded from learning identity hashes. No IDs, prompts, answer choices, correct answers, or explanations were changed by this review.

NetApp and VMware were removed from the active catalog at the user's request. Their source files and historical learner records are retained; they are excluded from topic tiles and catalog-based FSRS queues. Removing a catalog entry is not an account-data deletion.
